# Hospitality AI — Clinic Edition v3

美容クリニック向け「教材根拠型」AIホスピタリティ研修アプリの動作MVPです。iPhone Safariからホーム画面に追加できるPWAとして使えます。

## v3で追加した機能
- スタッフ / 管理者ログイン
- クリニック単位のデータ分離の土台
- 12問・4タイプ診断（共感 / ロジカル / 提案 / クロージング）
- 診断結果をクラウド側データへ保存
- 複数教材の登録、バージョン表示、有効/停止
- PDF/TXT/MDから検索用チャンクを作成
- PDFは可能な範囲でページ番号を保持し、評価結果に教材名・ページを表示
- 録音 → AI文字起こし
- 登録中の有効教材だけを根拠にAI採点
- 医院ごとに編集できる採点ルーブリック
- 6項目スコア / 根拠 / 改善点 / 言い換え / 次回課題
- 接客タイプは点数に使わず個別コーチングのみに使用
- XP / LEVEL
- 個人のロープレ履歴
- 管理者ダッシュボード（スタッフ数、回数、平均、スタッフ別状況）

## デモアカウント
- スタッフ: `staff@demo.local` / `staff123`
- 管理者: `admin@demo.local` / `admin123`

※ デモ用の簡易認証です。本番では Supabase / Firebase / Auth0 等の認証に置き換えてください。

## 起動方法
1. Node.js 20+ を用意
2. `npm install`
3. `OPENAI_API_KEY` を環境変数に設定
4. 必要なら `OPENAI_MODEL` を設定（未設定時 `gpt-5.6-luna`）
5. `npm start`
6. `http://localhost:3000`

## 重要な設計方針
- AIはスタッフの人格や感情を推測せず、会話上で観察できる行動だけを評価します。
- AIスコアだけで人事評価・処遇を自動決定する用途にはしないでください。
- 市販書籍・第三者教材の全文を商用サービスで利用する場合は、著作権者・出版社等との利用許諾を確認してください。
- 本番RAGでは、簡易キーワード検索をベクトルDB（pgvector / Pinecone 等）へ置き換えるのがおすすめです。
